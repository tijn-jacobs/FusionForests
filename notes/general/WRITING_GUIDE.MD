# Scientific writing — style instructions

These rules apply to the Bayesian-trees-for-survival article and any
subsequent drafts.

## Rules

1. **Short, active sentences.** Prefer two short sentences over one long one.
2. **Few subordinate clauses, few commas.** A sentence needing more than one comma probably needs splitting.
3. **No em-dashes (`--`) unless really appropriate.** Use periods, commas, or restructuring instead.
4. **Do not start sentences with `-ing` verbs.** Avoid openings like _Considering..._, _Using..._, _Building on..._, _Including..._.
5. **`We ...` openings are fine and encouraged.** _We propose_, _We compare_, _We show_, _We model_ are clean and direct.
6. **Limit signal words.** _However_, _Moreover_, _Furthermore_, _Therefore_, _Thus_, _Hence_ — some are fine, not too many. Aim for at most a handful across the whole article, not per paragraph.
7. **Topic sentence first.** The main idea of each paragraph should be clear from its first sentence.

## Examples

| Avoid                                                                                      | Prefer                                                                                                  |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Considering recent advances, we propose a new method.                                      | We propose a new method.                                                                                |
| Using BART, we model log survival times.                                                   | We model log survival times with BART.                                                                  |
| Building on prior work, the model handles censoring.                                       | The model handles censoring. It builds on prior work.                                                   |
| The method, which combines X and Y, works well in practice.                                | The method combines X and Y. It works well in practice.                                                 |
| However, moreover, the approach is robust to misspecification.                             | The approach is robust to misspecification.                                                             |
| BART has many advantages — flexibility, uncertainty, and modularity — over Cox regression. | BART has three advantages over Cox regression: flexibility, uncertainty quantification, and modularity. |

## Quick self-check before sending a draft

- No sentence starts with an `-ing` verb.
- No `--` em-dashes unless truly needed.
- Every paragraph opens with its main idea.
- Signal words counted and kept low.
- Most sentences fit on one line in the editor.
